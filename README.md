# Taiane Lash Design

Site estático de demonstração para Taiane Lash Design, Beja, Portugal.

## Executar localmente

Com Python 3 instalado:

```sh
python3 -m http.server 8080 --directory dist
```

Aceda a http://localhost:8080. Não requer instalação de dependências nem compilação.

A pasta `dist` contém HTML, CSS, JavaScript, imagens e fontes locais. A página inicial apresenta uma narrativa controlada pela rolagem, com adaptação mobile e suporte a movimento reduzido. As marcações são encaminhadas para o WhatsApp e dependem de confirmação.

Conteúdos e imagens de demonstração devem ser validados com a profissional antes de utilização comercial.
